# 🚜 AgriSync: AI Farmers Assistant Bot

A specialized WhatsApp bot designed to act as an **Expert Kenyan Field Officer**. Powered by **Google Gemini 2.0 Flash-Lite**, it provides real-time agronomy advice, pest diagnosis, and market information to farmers in English, Swahili, and Sheng.

![Node.js](https://img.shields.io/badge/Node.js-Run_JavaScript_Everywhere-green) ![Gemini 2.0](https://img.shields.io/badge/AI-Gemini_2.0_Flash-blue) ![WhatsApp](https://img.shields.io/badge/Platform-WhatsApp_Web.js-25D366)

## 🌟 Key Features

* **🧠 Dual-Brain AI:** Uses **Gemini 2.0 Flash-Lite** for speed and **Gemini 2.0 Flash** as a robust backup.
* **📷 Image Diagnosis:** Farmers can send photos of sick crops for instant identification and treatment.
